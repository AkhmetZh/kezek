# Kezek

**Kezek** is a web-based food pre-ordering system designed for the Astana IT University campus cafeteria.

## Problem

Students have limited time between classes and may spend a significant part of their breaks waiting in the cafeteria queue. They may also find that their preferred meals are no longer available.

## Proposed Solution

Kezek allows students to browse the cafeteria menu, check meal availability, place orders in advance, and select a pickup time slot. Cafeteria staff can manage incoming orders and update meal availability.

## Main Features

- Browse meals, prices, and availability.
- Search and filter menu items.
- Add meals to a cart and place an order.
- Select a pickup time slot.
- View order status and order number.
- Manage orders and meal availability through a staff interface.

## Project Scope

The initial version focuses on food pre-ordering and pickup. Online payment and food delivery are outside the current scope.
